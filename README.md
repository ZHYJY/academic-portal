# 学术检索链接平台

一个可点击跳转的国内外学术检索数据库导航页。收录 143 个数据库，覆盖 8 大类，支持关键词搜索、地区与访问方式筛选，并附国内外占比与分类构成图表。

## 收录范围

| 分类 | 数量 | 主要用途 |
| --- | --- | --- |
| 综合学术搜索 | 30 | 跨库检索、引文追踪、文献发现 |
| 期刊全文 | 30 | 期刊论文全文与过刊检索 |
| 电子书与古籍 | 31 | 电子书库、古籍与近代文献 |
| 学位论文 | 18 | 硕博论文与机构知识库 |
| 预印本与开放仓储 | 13 | 预印本、开放获取仓储 |
| 数据·专利·报告 | 11 | 统计数据、专利、机构报告 |
| 医学与生命科学 | 6 | 生物医学文献与临床资料 |
| 法律与社会科学 | 4 | 法律法规、判例与社科文献 |

按地区：国内 31 个，国外 112 个。
按访问方式：免费 114 个，部分免费 15 个，需登录 14 个。

## 检索与筛选

- **关键词搜索**：按数据库名称、简介与标签匹配，输入即筛。
- **地区筛选**：国内 / 国外。
- **访问方式筛选**：免费 / 部分免费 / 需登录。
- **分类切换**：按上面 8 类分组浏览。
- **构成概览**：页面顶部给出国内外占比与各分类数量分布，便于判断某个方向可用的库有多少。

## 使用

页面本身无需登录，点任意条目即跳转到该数据库官方站点。收藏页面或直接分享链接即可使用，不依赖本地环境。

## 说明

- 部分历史站点可能已改版、迁移或失效，遇到打不开的条目以官方站点公告为准。
- 标注为版权争议的站点（如 b-ok.org）已在条目内注明，使用时请遵守所在地法律法规。
- 数据库的收录范围与访问政策由各站点自行调整，本页只做入口索引，不代理访问、不提供全文。
